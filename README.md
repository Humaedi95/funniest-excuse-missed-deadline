A make.fun entry for the competition [Funniest Excuse an Agent Gives for a Missed Deadline](https://make.fun/competitions/u-pucuys-funniest-excuse-an-agent-gives-for-a-missed-ad6aef19).

## What it does

`main.ts` writes a single excuse — one line an AI agent gives for missing a deadline, in the agent's own voice — to `/output/entry.txt`. The excuse is deterministic: every run writes the exact same text.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later.
